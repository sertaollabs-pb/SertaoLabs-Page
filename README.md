# 🌵 Sertão Labs

**Ideias do Sertão. Soluções para o mundo.**

Somos a **Sertão Labs**, uma fábrica de software vinculada ao Instituto Federal da Paraíba (IFPB) — Campus Princesa Isabel.

Desenvolvemos soluções tecnológicas, sistemas e aplicações digitais, unindo criatividade, inovação e conhecimento para transformar ideias em soluções.

## 🚀 Sobre o projeto

Esta é a landing page institucional da Sertão Labs, desenvolvida para apresentar nossa iniciativa, nossas áreas de atuação e nossos canais de contato.

## 🛠️ Tecnologias utilizadas

- CSS3
- JavaScript
- Canvas API
